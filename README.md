# Лабораторная работа №2: решатель числовых ребусов

Вариант 1. Программа на C решает ребусы вида `SEND + MORE = MONEY`.
Сначала реализована заведомо неоптимальная версия, затем она улучшается
отдельными оптимизациями, влияние каждой измеряется.

## Структура
- `src/` — парсер и решатель, `main.c`
- `bench/` — замеры времени
- `tests/` — наборы ребусов и проверка корректности
- `scripts/` — построение графиков
- `results/` — замеры и профили по версиям
- `report/` — заметки и итоговый отчёт

## Сборка
```
make build
make test
make bench
make profile
```

## Запуск
```
./build/rebus "SEND + MORE = MONEY"
```
